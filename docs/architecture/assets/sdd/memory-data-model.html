Mô hình dữ liệu khái niệm

Ownership, Provenance và Auditability của Memory

Mô hình giữ lại message sinh ra Memory, scope cho phép sử dụng và trace của từng selection.

Ngữ nghĩa scope: user record key theo owner identity; workspace record key theo workspace; conversation record key theo conversation. Chroma được loại khỏi sơ đồ vì không phải Memory storage.
